# MET ETL Pipeline

Инструмент для загрузки, обработки и анализа изображений из коллекции Metropolitan Museum of Art.

## Возможности

- Загрузка случайных картин из API музея Метрополитен
- Обработка изображений (оттенки серого, размытие, границы, гамма-коррекция, резкость, смешивание)
- Асинхронная загрузка и параллельная обработка для ускорения работы
- Анализ датасета MetObjects.csv (топ-10 культур, временные графики)
- Логирование всех этапов в файл и консоль
- Интерфейс командной строки
